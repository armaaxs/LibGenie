🧞# LibGenie
The fastest, most modern Library Genesis wrapper for Python. Libgenie will be 
- Built using asynchronous libraries instead of the traditional 'requests'.
- Optimized for speed, using faster alternatives to BeautifulSoup4.
- Multi Mirror support.
- Advanced Filtering.
